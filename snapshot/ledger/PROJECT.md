# HealthTracker

## Overview
A women's health tracking app built for Emily. Features period tracking, hormone charts, sleep tracking, and symptom management. Aims to provide a comprehensive personal health dashboard.

## Tech Stack
- **Platform:** iOS (Swift, SwiftUI)
- **IDE:** Xcode
- **Type:** Health tracking app

## Architecture
- Xcode project (`HealthTracker.xcodeproj`)
- SwiftUI views with a custom design system (`DesignSystem.swift`)
- Local data persistence
